# hebi8L：操作逻辑

这份文档说的是独立 Mac 应用怎么操作、每个操作应该是什么行为。实现以它为准。窗口的样子见 [layout.html](layout.html)（用浏览器打开，两侧的页签可以点）。

应用的操作逻辑和原来的 VS Code 扩展（分支 `vscode-extension`，0.4.0）是同一套：认设定的灰字续写、想看时才调出来的设定卡、大纲图和浮标、能改全书并且每轮可以退回的助手。变的是外壳：一个为写小说做的窗口，不再借用代码编辑器。

一本书是一个 Markdown 文件夹。目录怎么摆、设定的 frontmatter、大纲图和连线、浮标、快照的去重与退回逻辑、提示词怎么拼、缓存断点、用量怎么算，都和扩展的 README 写的一样；书目录里的格式（文稿以及 `.novel-helper/` 下的标记、浮标、模板）保持兼容，同一本书扩展和应用都能开。差别在于快照：应用的助手快照和定时快照都存在本机应用数据目录（`snapshots/<书的标识>/`），不再写进书里的 `.novel-helper/snapshots`——扩展看不到应用的快照，应用也不读取、不迁移、不删除扩展或旧版留在书里的 `.novel-helper/snapshots`（并继续把它排除在扫描、快照和免问写入之外）。

## 1. 原样保留的操作

| 操作 | 行为 |
|---|---|
| 灰字出现 | 章节文件行尾停 750 毫秒；最多 100 字，可以分段 |
| 收下、放弃 | Tab 收下；Esc 或接着打字放弃，还在跑的请求一起断开 |
| 手动要一条 | ⌥\\，任何 md 或 txt 里都行 |
| 续写带什么 | 常驻条目、各层大纲或浮标节点、前几章、正文里提到的设定、本章正文；缓存断点不变 |
| 看设定卡 | 悬停在名字上，或光标在名字上按 ⌘I |
| 打开设定文件 | F12 或 ⌘ 点名字 |
| 书的结构 | 书名行、卷、大章、章的树；点章打开；标出有没有大纲和摘要 |
| 新建、重命名、移到废纸篓 | 书名行加卷加章、中间层级加章；新建章自动接编号，新建卷连第一章一起建；书名记在 `.novel-helper/project.json` 的 `title`；重命名和移到废纸篓会一并处理配套的大纲、摘要和浮标记录 |
| 设定 | 按类型分组；打开设定条目顶部显示与正文左对齐的条目名标题和「源码」/「表单」切换，标题下以两列属性网格编辑 frontmatter、细分隔线下方显示正文（不能无损改写或结束分隔线后没有换行时直接显示源码）；表单与右键操作都只动 frontmatter 里那一个字段 |
| 大纲和浮标 | 树上标着浮标；放到这里、设为衔接目标、加为并叙、取消第二个、前进、后退、让 AI 重新定位 |
| 浮标自动更新 | 本章每净增 1000 字顺带问一次模型，只沿连线走一步 |
| 设置和用量 | 左边七个分类（编辑器、外观、续写、助手、用量、iCloud、关于），右边一类一页，开关、滑块、分段按钮、弹出菜单即改即存；今天和本月的请求数与花费（续写、定位、助手分开列并合计）；日上限 |
| 看喂了什么 | 按 Markdown 排版渲染的只读页面：带了哪些条目、为什么带、完整提示词、用量 |
| 助手 | 通过 ACP 起本机的 Claude Code；故事目录内的改动放行，其余在面板里问；只有「允许一次」和「拒绝」 |
| 快照和退回 | 助手每轮前后存快照，手打内容按设定间隔和关书时存定时快照；看差异；整轮或按时间点退回，退回本身可以撤销 |
| 不做的 | 不在界面里拖动排序；章节和大纲不用表单填内容，正文和大纲直接在 md 里写 |
| 文稿安全 | 改写、改名或移到废纸篓前先检查；无法安全操作就停下。逐项改名或移到废纸篓中途意外失败时不回滚，列出已完成和未完成的操作并重建索引，标签页跟随实际状态 |

## 2. 窗口

### 2.1 分区

- **中间是写作面板**。正文限宽居中，窗口宽了两侧自动留白。没有行号、小地图、面包屑。上面一排标签页。
- **左栏是编辑入口**。三个分区：章节、大纲、设定。点一下，对应的 md 在中间的标签页里打开，用完整的编辑器改。改书名、新建章、新建卷、新建设定条目、重命名、移到废纸篓、切常驻、改别名、改类型都在左栏。
- **右栏只用来快速查看和对照**。三个页签：看大纲、看设定、助手。看大纲和看设定是只读的，每个条目旁边有「在中间打开」。同一个文件不会同时有两处在改。
- **顶栏**一排图标：收起左栏、并排、书名（iCloud 云盘可用且书不在 iCloud 里时点开有「存到 iCloud」）；右边是快照、查找、设置、收起右栏。
- **底栏**：续写开关和请求状态，点一下切换；今天写了多少字（设了目标时显示「今天 N / 目标 M 字」）；今天的请求数和花费（续写、大纲定位、助手三项相加），点开是按 Markdown 排版渲染的只读明细（续写、大纲定位、助手分开列并带合计，注明用订阅登录 Claude Code 时金额是按 API 价格折算的参考值）；当前章节的浮标；有 iCloud 冲突副本时显示「有 N 个冲突副本」，点一下打开第一个；最右在光标处于章节正文时显示「光标前字数 / 本章字数」，选中文字时显示「选中字数 / 本章字数」，其余情况显示当前文稿字数。
- 两侧都能收起。专注模式全屏并收起两侧，只剩正文。
- 设置窗口按 macOS 系统设置分成左边七个分类（编辑器、外观、续写、助手、用量、iCloud、关于）、右边一类一页，不占边栏。「编辑器」和「外观」页顶部显示实时预览；外观可选跟随系统、亮、暗；iCloud 页显示云盘是否可用、放书的文件夹并提供「在访达中显示」；关于页显示应用名与版本；只有顶部一条是拖动区。
- 界面上不放「点一下打开」这类操作提示文字。

### 2.2 左栏

- **章节**：书的结构树。最上面一行显示书名（存于 `.novel-helper/project.json` 的可选字段 `title`，没有时用文件夹名；写回时保留其他全部字段与原有格式；大纲仍沿用「全书」概念和文件名）：双击书名行就地编辑（回车确认、Esc 取消、空名不允许），书名行的 `⋯` 菜单和「文件」菜单里也有「重命名书…」，只改 `title` 不改文件夹名。每个节点后面标着有没有大纲、摘要，正在编辑的章在树里选中。鼠标移到书名行右侧出现「＋卷」「＋章」，移到卷或幕等中间层级出现「＋章」，点按走新建逻辑建在对应位置下（新建卷一并建第一章）。每一行右侧有 `⋯` 按钮，与右键菜单一致：书名行为重命名书…、新建卷、新建章、在访达中显示；卷或幕为重命名、新建章、新建下一级、在访达中显示、移到废纸篓…；章为重命名、在访达中显示、移到废纸篓…。移到废纸篓先弹确认框写明子层级数、章数、总字数以及一并移走的大纲、摘要、浮标记录，并注明「可以在访达的废纸篓里放回」；确认后先保存全部（助手运行中或有未解决冲突时不执行并提示原因），按与改名相同的配套规则用 `shell.trashItem` 移入系统废纸篓，已打开的对应标签页自动关闭；中途有项目失败时停下报告已移走和未移动的项目并重建索引，不回滚。
- **大纲**：大纲目录里的文件，按层级列出，点一下打开来改。
- **设定**：按类型分组。分组用条目 frontmatter 里的 `type`，没写就用它所在的顶层文件夹名。世界观、人物、物品、势力这些分类由作者自己起名；鼠标移到分组名一行右侧出现 `＋`（打开新建对话框并预选这一组），列表最底下是淡色文字「＋ 新建条目」（预选当前打开设定条目的类型，没有打开设定条目时预选第一个类型）；新建对话框里输入名字、点选已有类型小块或点「＋ 新类型」原地输入新类型，下方实时显示 `建在 <文件夹>/<名字>.md`，名字为空、重名或不合法时「新建」不可点，新建后打开该条目。每个条目右侧 `⋯` 与右键菜单提供重命名、切常驻、改别名、改类型、在访达中显示、移到废纸篓…（只移走这一个设定文件）。

### 2.3 右栏

- **看大纲**：大纲图列成树，标着当前章节的浮标。下面显示选中节点的内容和主线上的下一个节点。浮标的全部操作在这里。焦点在别的文件里时，这些操作说的仍然是上一个打开的章节。
- **看设定**：顶上一个按名字或别名找的输入框，下面是分组列表和选中条目的卡片：名字、类型、是否常驻、别名、摘要和正文。
- **助手**：对话、许可卡片、每轮改动的文件列表。发消息时自动带上中间正在编辑的文件、光标在第几行、选中的文字。agent 报出模型或思考档位选项时，发送按钮左侧的按钮弹出模型列表和强度分段按钮切换，并按 agent 记住选择（首次没有缓存列表时在面板显示后后台启动 agent 开会话获取，中途切换 agent 会先结束旧连接再启动新 agent；有缓存时仍等发第一条消息才启动；新开或恢复会话时先恢复模型，再按新列表恢复思考档位；记住的值不在本次列表里时本次显示 agent 当前值，记忆原样保留）。
- 右栏显示什么由作者自己点，不跟着光标自动换内容。唯一自动的是大纲上的浮标标记。

### 2.4 写作面板的手感

参考了纯纯写作（Pure Writer）桌面版的界面，没有使用它的代码。

- 大纲和其他非章节文件按 Markdown 原样显示，不渲染、不隐藏标记；设定条目在编辑器里始终保有完整全文，顶部一行与正文左对齐显示只读条目名标题（文件名去掉扩展名）和右侧淡色「源码」/「表单」按钮，表单模式下隐藏开头的 frontmatter 段落并在标题下显示与正文同宽左对齐的两列属性网格与细分隔线（类型小块点开列出全书全部类型并可在底部输入新类型回车采用，Esc 或点外部关闭后焦点回到类型；别名和字符串列表为带 `✕` 删除的小块加无边框「＋ 添加」输入框，非组字回车添加，粘贴含逗号或顿号的文字按分隔符拆成多个并忽略重复项；常驻和布尔字段用开关；摘要与字符串字段无边框原地编辑，摘要空时显示「添加摘要」，磁盘上保持单行值、自动折行显示，回车无操作，粘贴换行变空格；空着的固定字段不写入文件；每次改动立刻无损写回对应字段，输入法组字期间在组字结束时写回，统一走编辑器的 ⌘Z 撤销重做、自动保存与冲突处理；在「表单」和「源码」之间切换保留撤销历史，查找或全书搜索定位到隐藏的 frontmatter 时自动切到源码模式选中匹配，frontmatter 结束分隔线后没有换行、无法解析或不能无损改写时保持源码显示且不动文件），细分隔线下方只显示正文；只读的「用量和估算花费」与「上次发给模型的内容」报告按 Markdown 排版渲染，可选中复制。设定里的名字下面有一条细点线。
- 章节正文的排版和手感增强全都是显示或编辑交互效果，不往文件里写任何字符，和扩展打开同一本书保持兼容：
  - **光标**：用 `drawSelection` 画主题色（`--accent`）光标，呼吸式淡入淡出闪烁，移动时约 80 毫秒平滑过渡；输入法组字期间关闭位移动画，不影响组字。
  - **标题**：`# ` 开头的各级标题用单独的标题样式，字号可调、可选居中；光标不在这一行时隐藏行首的 `#` 和空格，光标进到这一行时显示出来方便编辑。
  - **段落、行距与宽度**：可选首行缩进两字（行首已经有全角空格、空格或 Tab 的行不再额外缩进）；段间距分「无、半行、一行」三档，不管文件用空行分段还是一行一段，看起来的段间距都一样，空行分段时把空行显示得矮一些且光标仍能停在空行上；行距分「紧、适中、松」三档；正文宽度按每行字数调节。
  - **字体**：提供苹方、宋体，以及本机已安装时才列出的楷体、霞鹜文楷，并可选「其他…」填入任意字体名。
  - **聚焦段落与打字机滚动**：「聚焦段落」（当前段落正常显示，其余段落降低不透明度）与「打字机滚动」（正在写的那一行滚到屏幕中间）是两个独立开关。
  - **退格删缩进**：光标紧跟在行首缩进后面、前面只有空白时，按一次退格删掉整段缩进。
  - **今天字数**：按全书章节当天的净增字数计算（删字减掉），沿用现有字数统计口径，按书分开存在本机应用数据目录；「一天从几点开始」可设（默认 0 点，比如设成 4 点时凌晨 3 点写的字算前一天）。
- 回车另起一段时沿用上一段的段首缩进。
- 引号、括号自动补成一对（开关可控）；删左半边时右半边一起删；光标在右引号或右括号前按回车或 Tab 跳出去。有灰字时 Tab 先收灰字。
- 没有灰字、也不在右引号前时，Tab 照常输入一个制表符。
- 主题可选跟随系统、亮、暗。
- 并排是左右两个编辑器对照，只做一层。

## 3. 打开一本书

- **一本书就是一个文件夹**。⌘O 选文件夹，选中的文件夹就是故事的根。扩展里「工作区」加「故事目录相对路径」那一层没有了。
- **选的文件夹不是书**：里面最多往下四层有带标记的故事空间时，列出来点一个就打开。空文件夹或没初始化的，走初始化：问目录用中文名还是英文名，列出要建的东西勾选。已经有的不列出来，也不覆盖。
- **启动**：重新打开上次的书、上次的标签页和光标位置。没有上次的书时，显示最近的书、「iCloud 里的书」（有书时）、「打开文件夹」和「新建一本书」；最近的书和 iCloud 里的书都显示书名（`project.json` 的 `title`，没有时用文件夹名），窗口标题和顶栏也显示书名。
- **多本书**：一本书一个窗口。同一本书再开一次，切到已有的窗口。
- **没有「信任文件夹」**：服务商、模型、地址、key、单价、日上限、助手用的命令只存在应用自己的设置里，从不从书的文件夹读。打开别人给的文件夹改不了这些。
- 预设的 Claude Code 适配器会采用书目录里的 `.claude` 设置，其中的放行规则和钩子不经过应用的许可卡片；用别人给的书之前先看一眼这个目录。
- **目录规则**：认默认的中文和英文目录名。

## 4. 设定卡

- **调出**：鼠标停在名字上约 0.4 秒；或者光标在名字上按 ⌘I。应用不主动弹。
- **内容**：名字、类型、是否常驻、别名、摘要或正文前 300 字。一个名字对应多条设定时，几张卡都列出。
- **卡上的操作**：⌘↩ 或点「打开」在标签页里打开设定文件；⌥⌘↩ 并排打开；Esc 关掉，光标回原处。
- 设定文件保存、新建、改名、删除后马上生效。

## 6. 输入法组字时的灰字

应用拿得到真实的组字状态，不再像扩展那样靠「中文后面跟着小写字母」来猜。

1. **组字开始等于打字**：灰字立刻消失，在跑的请求断开。
2. **组字期间什么都不做**：不计时、不发请求、不显示灰字。Tab、Esc、回车、空格、数字键全归输入法，应用不拦。⌥\\ 这时也不响应。
3. **上屏之后**：按普通打字算，从上屏那一刻起等 750 毫秒，在行尾就发请求。
4. **取消组字**：正文没变。回到同一个位置、正文也相同时，直接显示上一次的灰字，不重新发请求。
5. **没有拼音猜测**：「他说hello」这种中文后面跟英文的行尾，照常自动续写。
6. **助手输入框**：组字期间按回车是选词，不发送。
7. 日文输入法、听写、长按出重音符号、表情面板都走同一套组字状态。

灰字的状态是一个纯函数的状态机：输入是事件（打字、光标移动、组字开始、组字结束、停顿到时、收到回答、Tab、⌘→、Esc、失去焦点），输出是新状态和要做的事（发请求、断开请求、显示、隐藏、插入文字）。上面每一条都有单元测试。

其他规则和扩展一样：自动请求只在章节文件的行尾（光标后面只能有收尾的标点和空白）；⌥\\ 在任何 md 和 txt 里都行；到了日上限不自动发；续写关着不发；收下一次灰字是一步撤销。

## 7. 保存和外部改动

- **自动保存**：停止打字 1 秒后保存；切走标签页、窗口失去焦点、给助手发消息之前也保存。没有手动保存这一步。
- **组字期间不自动保存**：拼音还没上屏时不计时、不存。关窗或退出时先让编辑器失去焦点，输入法随之结束组字，屏幕上的内容照样存下来。
- **换行符和编码**：文件原来用什么换行符，写回去还是什么。不是 UTF-8、或者混用两种换行符的文件不打开来改，在界面上说明原因。
- **什么会触发续写**：只有作者在编辑器里的动作：打字、收下灰字、用鼠标或方向键把光标移到行尾。切标签页、启动时恢复光标、外部改动后重读都不触发。有选区时不出灰字。
- **写盘**：覆盖已有文件时先写临时文件再改名；新建文件使用独占创建，不覆盖已有文件。
- **磁盘上的文件被别处改了**（助手、别的编辑器、git）：编辑器里没有未保存内容时，直接重新读入，光标尽量留在原处。有未保存内容时停下不写，在编辑器顶上提示，三个按钮：看差异、留我的、用磁盘的。
- **撤销**：助手改的内容不进编辑器的撤销，用快照退回。
- **定时快照**：书里有文件保存、新建、改名或改写且距离上一份快照（不论定时还是助手快照）达到设定间隔时，操作本身完成后在后台存一份整本书的定时快照，当次操作不等快照结束，失败时不影响已完成的操作并在顶栏提示一次「定时快照没存上」和原因；首次开书基线尚未读完时的书内写入会先等基线建完再写（基线读取失败时不缓存，在建成前只提示一次，并在下一次书内写入前重试），后台定时快照扫描进行时同一本书的下一次写入与助手开轮快照也会等扫描结束再执行。关书、关窗、退出时若上一份快照之后有改动也存一份，退出前等待后台快照落盘，没有改动或助手正在跑一轮时不存。间隔默认 10 分钟（填 0 关闭，关闭时不读基线、不持有全书内容；从 0 改为非 0 时对已打开的书以那一刻的内容建立基线），默认保留 100 份，与助手快照保留数分开算。顶栏「快照」按时间合并列出各快照，可查看每个改动文件的差异并「退回到这个时间点」，退回与撤销退回写回文稿时先写同目录临时文件再改名覆盖，退回前先保存当前状态，退回本身也可撤销；有未保存内容、未解决冲突或受阻文件时不退回。

### 两台 Mac 同步

- 在一台 Mac 上点顶栏书名菜单（或「文件」菜单）里的「存到 iCloud」，确认后会先保存全部更改，把整本书复制到 `~/Library/Mobile Documents/com~apple~CloudDocs/hebi8L/<文件夹名>/`（从确认开始保存到切换完成期间阻止关窗、两个入口均不可用，窗口盖上「正在存到 iCloud…」遮罩挡住编辑和修改操作，失败时去掉遮罩、恢复正常关窗并回到原书；先记下要复制文件的路径、大小与修改时间并复制到同目录 `<文件夹名>.partial`，跳过 `.git`、`node_modules` 和旧的 `.novel-helper/snapshots`，其余文件含 `.novel-helper/` 下的内容全部复制，逐个文件比对字节一致且复核原书文件清单、大小和修改时间未变后，先用非递归 `mkdir` 建出 `<文件夹名>` 再将 `<文件夹名>.partial` 改名过去；复制期间原书被改动则中止并提示，目标已存在时不覆盖，改名失败也不碰目标文件夹，任何一步失败都会把 `.partial` 移进废纸篓并提示原因，移入废纸篓也失败时一并说明并给出残留 `.partial` 路径、不自动删除；有未解决的冲突、助手正在运行一轮或目标已有同名文件夹时不执行并提示原因）。原来的文件夹保留不动；复制成功后关掉原窗口、打开 iCloud 里的这一份，把「最近打开」里的原路径换成新路径，并在新窗口顶部通知条提示一次。
- 在另一台登录同一个 Apple 账户的 Mac 上打开应用，欢迎页在「最近打开」下方列出「iCloud 里的书」（读取 `hebi8L/` 下的每个文件夹，没有书时不显示；欢迎页显示期间监听该目录，新同步来的书自动出现；与「最近打开」不去重），点一下即可打开接着写。本机不存在 `~/Library/Mobile Documents/com~apple~CloudDocs` 时不显示任何 iCloud 入口；书已经在 iCloud 云盘里时不显示「存到 iCloud」。
- 在访达里对书的文件夹选「保留下载」，免得章节被收起成只在云端、本机读不到完整文件。
- 快照每台 Mac 各存各的，存在本机的应用数据目录里，不进 iCloud。存到 iCloud 后，应用按新路径另起快照，旧的快照还在本机但界面里看不到。
- 冲突副本只在 iCloud 云盘（`~/Library/Mobile Documents/`）里的书上识别；在 iCloud 里不要把文件起名成「某名 2.md」同时又有「某名.md」，会被当成冲突副本。
- 两台 Mac 同步前都改了同一个文件时，iCloud 会在同一文件夹下留下「原名 + 空格 + 数字（≥ 2）+ 原扩展名」的副本：
  - `.md` 文件的冲突副本（且同名原 `.md` 文件也在同一文件夹内）不当作普通条目参与编号、排序、字数和设定匹配，而是挂在左栏章节、大纲、设定三棵树的原文件下方，标「冲突副本」；底栏显示「有 N 个冲突副本」，点击打开第一个。
  - 点开冲突副本会用差异视图显示原文件和副本的差异，提供「用副本替换原文」和「删除副本」两个操作，都要先确认：执行时核对内容哈希，若文件刚被改过则不执行并刷新差异；替换前先存一份包含当前原文的快照（`conflict`；若原文超过 5 MB 或无法存进快照则不替换），存完再核对原文未变后用原子写入覆盖原文件并把副本移到废纸篓；删除副本核对副本哈希后用系统废纸篓（`shell.trashItem`）移走，不直接删除。原文件或副本在编辑器里有未保存内容或冲突时不执行，并提示原因。
  - `.novel-helper/buoys/` 下的浮标文件和 `.novel-helper/project.json` 出现按同一规则判定的 `.json` 冲突副本时，读取时直接忽略，不报错、不显示，也不做合并。

## 8. 应用自己管的东西

| | 做法 |
|---|---|
| 设置 | 存在 `~/Library/Application Support/Novel Helper` 下（沿用原用户数据目录和钥匙串服务名，不丢已有数据），项目和扩展的设置一一对应，另含应用自己的定时快照间隔和保留份数 |
| API key | 用系统钥匙串保管的钥匙加密后存在应用目录里；界面上只显示已设置或未设置，从不显示 key 本身 |
| 用量账本 | 应用自己一份，所有窗口共用；记录续写、大纲定位与助手每轮用量（助手按当前选中的 model 选项记录四种 token 数及会话累计金额的本轮差值，会话重开从头算，未报金额时只记 token；报告里续写、定位、助手分开列并带合计，注明订阅登录 Claude Code 时金额为按 API 价格折算的参考值） |
| 今天字数 | 存在应用目录 `word-counts/` 下，按书分开记录全书章节的当天净增字数 |
| 助手的对话 | 存在应用目录里，按书分开，不进书的文件夹 |
| 快照 | 助手快照和定时快照都存在应用目录 `snapshots/<书的标识>/` 下（`<书的标识>` 取书根目录 `realpath` 的 SHA-256 前 16 位十六进制，目录内另写 `book.json` 记录真实路径），`timed.json` 与 `timed-objects/` 独立保留并与 `objects/` 按哈希硬链接去重；书内已有的 `.novel-helper/snapshots/` 原样不动且排除在扫描和快照之外 |
| 找到 `npx` | 从程序坞启动时 PATH 很短；应用启动时跑一次登录 shell 取 PATH |
| 文件监听 | 监听故事文件夹，树和索引跟着更新 |
| 删文件、挪文件 | 不做拖拽挪动文件，树上可「在访达中显示」；章节、卷/幕（含配套大纲、摘要、浮标记录）、设定条目和冲突副本删除时统一经确认后移入系统废纸篓（`shell.trashItem`），可从废纸篓放回 |
| 日志 | 写到应用目录下，菜单里有「打开日志」 |
| 界面语言 | 中文。字符串集中放在一处 |

不支持的：远程文件夹（只能开本机上的文件夹）、多根工作区。

## 9. 代码怎么分

```text
src/core  src/llm  src/storage  src/acp     续写、大纲图、浮标、快照、模型客户端、ACP 客户端；不依赖界面
src/main            主进程：窗口、菜单、打开一本书、索引和文件监听、设置、密钥、用量、浮标、助手
src/preload         主进程给界面开的接口
src/renderer        界面：编辑器、左栏、右栏、标签页、底栏、设置窗口
src/test            单元测试
e2e                 把应用启动起来走一遍的测试
examples            示例书；测试只用它的临时副本
```

- Electron，界面用 React 和 CodeMirror 6。界面进程碰不到 Node，只能走 `src/preload` 开的接口。
- 覆盖已有文件先写临时文件再改名；新建文件使用独占创建。
- 启动应用的测试用不需要 key 的本地假服务，不碰钥匙串。

- 主进程各功能分别注册 IPC，注册列表在 `src/main/register.ts`；窗口关闭清理通过 `MainContext.onBookClosed`登记；书索引的 `onChanged`、`onFileChanged` 支持多监听，并返回取消监听函数。
- 左右栏各面板独立，切换或收起只隐藏；面板通过 `useWorkspace().current()` 读取当前文档和选区，通过 `open()`、`saveAll()` 打开和保存。
- 文档管理、欢迎页、顶栏、冲突条分别独立；界面命令在 `shell/commands.ts` 的表中登记。

## 10. 分批

1. **骨架，能写一章**：窗口、菜单栏、顶栏、底栏；打开一本书；左栏的章节分区；编辑器和自动保存；灰字续写和输入法规则；五项设置（续写开关、自动还是手动、服务商、模型、API key）；用量和字数。这一批没有浮标，续写按同名大纲文件带大纲。
2. **看设定、大纲、浮标**：设定卡；左栏的大纲和设定分区；右栏的看大纲和看设定；浮标的整套流程；⌘P；并排；「看喂了什么」和用量明细。
3. **助手**：右栏的助手页签；ACP；许可；快照、差异、退回；对话保存。
4. **搭架子和收尾**：初始化、新建章和卷、重命名、补标记；全部设置项；全书搜索；专注；打包；README。
